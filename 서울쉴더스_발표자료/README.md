## 🎯 발표 내용
서울쉴더스 프로젝트의 다음 내용을 중심으로 구성되어 있습니다.

1. 프로젝트 기획 및 배경
2. 데이터 수집 및 분석
3. 데이터 시각화
4. 서비스 구현
5. 프로젝트 결과 및 개선 방향

## 🛡️ 프로젝트 소개
서울시 공공데이터를 활용하여 지역별 치안 및 안전 환경을 분석하고 시각화하는 프로젝트입니다.
서울쉴더스 프로젝트의 발표자료와 웹 기반 발표자료를 관리합니다.
