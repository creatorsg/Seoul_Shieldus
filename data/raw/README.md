# Raw Data

서울시 공공데이터를 활용한 원천 데이터(Raw Data)입니다.

## 데이터 목록

| 데이터 | 설명 |
|---|---|
| 서울시 등록인구 | 서울시 지역별 주민등록인구 통계 |
| 상권분석서비스(영역-자치구) | 서울시 자치구 공간 정보 |
| 서울시 5대 범죄 | 살인·강도·강간·절도·폭력 발생 통계 |
| 서울시 가로등 위치 | 가로등의 위도·경도 위치 정보 |

## 활용 목적

인구, 상권, 범죄 및 가로등 위치 데이터를 결합하여
서울시 지역별 안전환경을 분석하는 데 활용합니다.
